Vanniddhi is a modern, mobile-first e-commerce web app tailored for plant nurseries and décor shops that want speed, simplicity, and reliability without heavy frameworks. Built on a lightweight LAMP stack (PHP 8, MySQL/MariaDB, Apache) with vanilla JavaScript and semantic HTML/CSS, it deploys cleanly on shared hosting or Bitnami/Lightsail. The interface is responsive, accessible, and brandable, featuring a sticky mobile checkout bar, fluid product cards, and fast navigation.

Core shopping features include a localStorage-backed cart with quantity controls, live subtotal/total, image thumbnails, and removal actions. Checkout offers two clear paths: “Pay Online” redirects to a secure hosted payment page (ICICI or any compatible gateway), while “Download Order Sheet” generates a branded PDF invoice instantly using jsPDF—perfect for COD, in-store pickup, or phone orders. Orders are persisted in MySQL via `invoices` and `invoice_items`, storing invoice numbers, customer details, line items, and statuses (Pending/Paid/Failed/Cancelled), enabling clear back-office reconciliation and customer support.

Payment integration is intentionally straightforward. Banks/PGs provide Merchant ID, Access Code, HMAC/Webhook secrets, currency, and test/prod gateway URLs. You drop these into `/pay/env.php`, and the app handles the rest: `/pay/create-order.php` prepares a signed form (no card data touches your server), `/pay/callback.php` reconciles the browser return, and `/pay/webhook.php` verifies the final status server-to-server for tamper-proof settlement.

Security and ops are first-class. Secrets live outside version control, payloads are HMAC-signed and verified, and responses are validated before updating order status. The codebase favors clarity: plain PHP routes, conventional SQL schema, minimal dependencies, and helpful inline comments. The repo includes sample SQL, an `.env.sample`, and setup docs so you can stand up a demo quickly.

Extensibility is built-in: add coupons, GST, delivery zones, inventory locks, email/SMS receipts, or an admin dashboard with charts and order filters. Performance is practical—compressed images, lightweight CSS/JS, and client-side caching—so pages feel snappy on low-end phones.

Vanniddhi’s goal is pragmatic commerce: professional checkout, clean invoices, and a delightful shopping experience with zero vendor lock-in.
